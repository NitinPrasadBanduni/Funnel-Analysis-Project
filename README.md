# Customer Funnel Analysis

## Project Overview
This project analyzes customer behavior across multiple stages of the conversion journey to identify drop-off points and improve conversion rates.

## Objectives
- Analyze customer activity data
- Identify bottlenecks in the conversion funnel
- Study city-wise conversion performance
- Evaluate revenue contribution and subscription trends

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Key Analyses
1. Customer Demographics Analysis
2. Revenue Analysis
3. Payment Method Analysis
4. Conversion Funnel Analysis
5. Customer Transition Time Analysis
6. City-wise Funnel Performance

## Key Findings
- Identified major customer drop-off stages.
- Compared conversion performance across cities.
- Analyzed subscription and revenue trends.
- Evaluated customer transition times between stages.
